# Returns Policy

## 1. Returns Overview

Customers may be eligible to return products depending on:

- Product category
- Order status
- Return window
- Product condition
- Reason for return
- Applicable return policy
- Seller or fulfillment conditions

Return eligibility must be verified against the applicable order and product policy before a return is confirmed.

The AI assistant must not promise that a return will be accepted without verifying eligibility.

---

## 2. Return Eligibility

A product may be eligible for return when:

- The order is within the applicable return period.
- The product belongs to a return-eligible category.
- The product meets the required condition.
- The return reason is supported by the applicable policy.
- Any required documentation or evidence is available.

Some products may be non-returnable because of product type, hygiene requirements, customization, regulatory restrictions, or other policy conditions.

---

## 3. Return Window

The return period depends on the product and applicable store policy.

The customer should check the order-specific return information whenever available.

The AI must not invent a specific number of return days unless that information exists in the configured knowledge base or order system.

If the return period has expired, the customer should contact support to determine whether any exception or alternative resolution is available.

---

## 4. How to Request a Return

Customers should provide:

- Order ID
- Product name or item information
- Reason for return
- Description of the issue
- Photos or other evidence when requested

The support system should first verify the order and return eligibility.

If the product is eligible, the customer can be provided with the applicable return instructions.

---

## 5. Return Process

A typical return process may include:

1. Customer submits a return request.
2. Order and product eligibility are verified.
3. Return reason is recorded.
4. Additional evidence is collected if required.
5. Return request is approved or rejected.
6. Return instructions are provided.
7. Product is collected or shipped back.
8. Returned product is received and inspected when applicable.
9. Refund or replacement is processed according to the applicable policy.

The exact process may vary by product and return reason.

---

## 6. Return Request Status

### Return Requested

The customer has submitted a return request and it is awaiting review or processing.

### Return Approved

The return request has been approved and the customer can follow the provided return instructions.

### Return Rejected

The return request was not approved based on the applicable eligibility conditions.

### Return Pickup Scheduled

A return pickup has been scheduled with the applicable delivery or logistics provider.

### Return In Transit

The returned product has entered the return shipping process.

### Return Received

The returned product has been received by the seller or fulfillment center.

### Return Inspection

The returned product is being checked against the applicable return requirements.

### Return Completed

The return process has been completed and the applicable refund, replacement, or other resolution has been initiated.

---

## 7. Damaged Product

If a customer receives a damaged product:

1. Keep the product and packaging available.
2. Contact support as soon as possible.
3. Provide the order ID.
4. Describe the damage.
5. Provide photographs or other evidence if requested.
6. Follow the instructions provided by support.

The final resolution may depend on the applicable product and damage policy.

Possible resolutions may include:

- Return
- Replacement
- Refund
- Other support-approved resolution

The AI must not guarantee a particular resolution before verification.

---

## 8. Wrong Product Received

If the customer receives a product different from the product ordered:

1. Verify the order details.
2. Provide the order ID.
3. Identify the incorrect product.
4. Provide photographs or other requested information.
5. Follow the return or replacement instructions.

The support team should verify the order before confirming the resolution.

---

## 9. Missing Items

If an order contains fewer items than expected:

1. Check the order details.
2. Verify whether the order was split into multiple shipments.
3. Check the shipment status of the missing item.
4. Contact support if the item is not scheduled for another shipment.

Do not assume that an item is missing until the order and shipment information has been checked.

---

## 10. Product Condition

Returned products may need to meet specific condition requirements.

Depending on the applicable policy, requirements may include:

- Product is unused
- Product is undamaged
- Original packaging is available
- Accessories are included
- Labels or tags remain attached
- Manuals or included materials are present

Condition requirements vary by product and policy.

The AI should not claim that a product is eligible solely based on the customer's description.

---

## 11. Original Packaging

Some returns may require the original packaging or included accessories.

Customers should keep the original packaging when possible until the return process is complete.

If the packaging is unavailable, contact support to determine whether the return can still be processed.

---

## 12. Return Pickup

If return pickup is available, the logistics provider may schedule a pickup from the customer's delivery address.

Pickup availability can depend on:

- Customer location
- Product type
- Seller
- Carrier availability
- Return method

The AI should only provide pickup information confirmed by the return or logistics system.

---

## 13. Return Shipping

Return shipping requirements depend on the applicable return policy and reason for return.

The customer may receive:

- A prepaid return label
- A pickup arrangement
- Instructions to ship the product
- Another approved return method

The AI must not promise free return shipping unless the applicable policy confirms it.

---

## 14. Return Shipping Cost

Return shipping charges may depend on:

- Reason for return
- Product category
- Seller policy
- Shipping method
- Applicable return conditions

Customers should be informed of the applicable return-shipping requirements before completing the return.

---

## 15. Replacement Instead of Return

Some products may qualify for replacement instead of or before a refund.

Replacement availability depends on:

- Product availability
- Return eligibility
- Reason for return
- Seller policy
- Product condition

The AI should verify availability before promising a replacement.

---

## 16. Exchange

If exchanges are supported, eligibility may depend on the product, size/variant availability, return period, and applicable policy.

If the requested replacement variant is unavailable, the customer may need to use the standard return or refund process.

---

## 17. Return After the Return Window

Returns requested after the applicable return period may not be eligible.

Customers should contact support if they believe there are exceptional circumstances.

The AI must not automatically approve an expired return.

---

## 18. Non-Returnable Products

Some products may not be eligible for return.

Examples can include products that are:

- Personalized or customized
- Perishable
- Subject to hygiene restrictions
- Opened where policy prohibits return
- Restricted by applicable regulations
- Specifically marked as non-returnable

The exact list depends on the store's product-specific policy.

---

## 19. Sale or Discounted Products

Discounted products may have different return conditions depending on the applicable policy.

Customers should check the product or order-specific return terms.

The AI must not assume that a discounted product is either returnable or non-returnable without verifying the policy.

---

## 20. Gift Orders

Return options for gift orders depend on the store's applicable policy.

The person requesting the return may need to provide relevant order information.

Contact support if the normal return process cannot be used.

---

## 21. Return Inspection

Returned products may be inspected before the return is finalized.

Inspection may verify:

- Product identity
- Product condition
- Accessories
- Packaging
- Reported issue
- Compliance with return requirements

The final outcome may depend on the inspection result.

---

## 22. Return Rejected After Inspection

If a return does not meet the applicable requirements, the return may be rejected after inspection.

If a customer disagrees with the result, they should contact support and provide the relevant order and return information.

---

## 23. Return Status Not Updated

If the customer has already returned a product but the return status has not changed:

1. Verify the return or order ID.
2. Check available pickup or shipment tracking.
3. Confirm whether the return has reached the processing facility.
4. Contact support if the expected processing period has passed.

The AI should not claim that a return was received unless the available system confirms it.

---

## 24. Refund After Return

After an eligible return is received and processed, the applicable refund may be initiated according to the refund policy.

Refund timing can depend on:

- Return inspection
- Refund processing
- Payment method
- Payment provider
- Banking or financial institution processing

See the refund policy for additional information.

---

## 25. Return Cancellation

A return request may sometimes be cancelled before a certain processing stage.

Customers should contact support if they want to cancel an existing return request.

The support system should verify the current return status before confirming cancellation.

---

## 26. Return Request Information

When processing a return request, the support system may need:

- Customer ID
- Order ID
- Product/item ID
- Return reason
- Product condition
- Relevant evidence
- Return status

Only information necessary for processing the return should be requested.

Never request:

- Passwords
- OTPs
- PINs
- CVVs
- API keys
- Authentication tokens

---

## 27. AI Support Rules for Returns

The AI customer-support assistant must follow these rules:

1. Never invent a return policy.
2. Never invent a return deadline.
3. Never guarantee return approval without eligibility verification.
4. Never guarantee a refund or replacement before verification.
5. Ask for the order ID when order-specific information is required.
6. Use product-specific return rules when available.
7. Clearly distinguish between a return request and an approved return.
8. Do not claim that a return was received unless the system confirms it.
9. Do not claim that a refund was issued unless the refund system confirms it.
10. Escalate unusual or disputed return cases when necessary.
11. Protect customer information.
12. Never request passwords, OTPs, PINs, CVVs, or authentication credentials.
